A single pickup line, written as if a vending machine were flirting with a
passing human — 142 characters, one line, no trailing newline.

> Hey, gorgeous — you must be exact change, because the second you walked by, my coils started spinning and my B7 light hasn't stopped blinking.

## How it works

`main.ts` (Node.js standard library only) validates the entry gate — 1 to 200
characters, not only whitespace, single line, valid UTF-8, no control
characters, and at least one word from the machine's own world — then writes
the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
node main.ts
```

Run it twice and the output is byte-identical.
